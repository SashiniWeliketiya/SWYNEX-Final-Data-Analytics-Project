## 🚀 1. Project Overview
The primary goal of this project is to analyze customer demographic and behavioral patterns from a retail dataset, clean and process the data using Python, and translate raw data into actionable insights through an interactive Power BI dashboard. 

---

## 🎯 2. Problem Statement
Retail stores and shopping malls often struggle to identify high-value customer segments. Without clear segmentation based on customer age, annual income, and spending scores, marketing campaigns fail to target the right audience. This project addresses this gap by segmenting mall customers to optimize marketing strategies and improve customer engagement.

---

## 📂 3. Dataset Information
* **Dataset Name:** Mall Customers Dataset
* **Source / Description:** Contains customer demographic attributes including Customer ID, Gender, Age, Annual Income (k$), and Spending Score (1-100).
* **Format:** CSV

---

## 🧹 4. Data Cleaning & Processing
Before analysis, the dataset underwent rigorous data quality checks:
* Handled missing or null values to prevent bias in aggregation.
* Verified and standardized data types for numeric fields (Age, Income, Spending Score) and categorical fields (Gender).
* Ensured no duplicate customer records existed.

---

## 💻 5. Exploratory Data Analysis (EDA) & Python Scripts
Python was utilized for initial data exploration, statistical summary generation, and correlation analysis:
* Checked distributions of customer ages and annual incomes.
* Discovered purchasing trends and spending score variations across different demographics.

---

## 📈 6. Interactive Power BI Dashboard
An interactive and dynamic dashboard was built using **Power BI** to present visual summaries:
* **KPI Cards:** Display aggregate metrics such as Total Annual Income and Age distributions.
* **Interactive Slicers:** Allow dynamic filtering by customer gender (`Male` / `Female`).
* **Visual Charts:** 
  * Bar charts comparing spending scores across segments.
  * Relationship plots exploring age vs. annual income dynamics.

---

## 💡 7. Key Business Insights
* **Spending Behavior:** Female customers exhibit a slightly higher aggregate spending score compared to male customers within the analyzed sample.
* **Income vs. Spending:** Customers with mid-range incomes often display high spending variability, indicating lifestyle-driven purchasing rather than income-driven purchases alone.
* **Targeted Marketing:** Slicer functionality enables real-time isolation of specific customer demographics, allowing marketing teams to design tailored promotional campaigns.
